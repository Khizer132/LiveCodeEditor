# Live Code Editor

A simple web-based code editor that allows you to write and preview HTML, CSS, and JavaScript in real time.

## Features
- Live preview of code output
- Separate panels for HTML, CSS, and JS
- Clean, responsive design

## Usage
1. Open `index.html` in your browser.
2. Start typing code in the editor panels.
3. See the output live!
